## أ) قرارات مؤكدة من العميل

| المعرّف | القرار | الأثر الملزم |
|---|---|---|
| **C-01** | أربعة أدوار: سوبر أدمن، مدرس، مساعد، طالب. | كل شاشة وسياسة تُبنى على هذه الأدوار فقط. |
| **C-02** | **المدرس هو وحدة ملكية البيانات**، لا السنتر/البلد. السنتر والمدينة معلومة تنظيمية داخل مساحة المدرس. | تشابه الأسماء بين مدرسين لا يشارك بيانات. كل جدول أعمال يحمل `teacher_id` كجذر ملكية. |
| **C-03** | للطالب **حساب دخول عالمي واحد**، و**ملف أكاديمي مستقل** عند كل مدرس. | فصل صارم بين الهوية والملف الأكاديمي؛ لا يرى الطالب مدرسًا غير مرتبط به. |
| **C-04** | السوبر أدمن يدير الحسابات والدعوات والمتابعة، واطلاعه الأكاديمي **للقراءة فقط**؛ لا يعدّل حضورًا أو درجات ولا ينتحل هوية مدرس. | لا سياسة RLS تمنحه كتابة أكاديمية، ولا سياق «انتحال» في الإصدار الأول. |
| **C-05** | المساعد يمنحه المدرس **أفعالًا محددة + نطاق مجموعات**، وتُفرض على الخادم لا بإخفاء أزرار. | سياسات RLS تعتمد العضوية والنطاق، لا معرّفات يرسلها العميل. |
| **C-06** | دخول الطالب: **هاتف + كلمة مرور**، أو **كود طالب فريد + كلمة مرور** عند غياب رقم مستقل. | لا بريد إلكتروني إلزامي، ولا SMS مدفوع. |
| **C-07** | المدرسون بانضمام **بدعوة من الإدارة فقط**؛ لا تسجيل عام. | مسار التسجيل العام مغلق من أول يوم. |
| **C-08** | ربط الطالب بمدرس عبر **دعوة + قبول**؛ لا ربط تلقائي بتشابه الهاتف أو الاسم. | علاقة معلّقة حتى القبول. |
| **C-09** | استعادة كلمة مرور الطالب **بمساعدة المدرس**، بلا SMS أو بريد إلزامي. | تصميم استعادة موثّق في `AUTH_DESIGN.md` مع خطر متبقٍ يجب اعتماده. |
| **C-10** | الحضور: حاضر / غائب / متأخر / غياب بعذر. **عدم الرصد ليس غيابًا**، وتعديل الحضور يُسجَّل بقيمته القديمة والجديدة. | قيد فرادة على (حصة، طالب)، وجدول تدقيق للتعديل. |
| **C-11** | الدرس: شرح مكتوب + صور + معادلات + **يوتيوب مضمّن** داخل الصفحة. لا رفع فيديو. | استضافة الفيديو خارج المنصة. |
| **C-12** | الأسئلة: اختيار من متعدد بإجابة صحيحة واحدة، وصح/خطأ. **لا مقالي** في الإصدار الأول. | التصحيح آلي بالكامل عبر معرّفات الاختيارات. |
| **C-13** | سحب عشوائي **مستقل لكل محاولة**، بلا تكرار السؤال داخل المحاولة، مع خلط ترتيب الأسئلة والاختيارات، و**تقاطع الأسئلة بين الطلاب مسموح**. | لا وعد بنسخ متمايزة تمامًا. |
| **C-14** | نسخة المحاولة **ثابتة**، والوقت والحفظ والتصحيح والسحب **على الخادم**. | لا يُرسل مفتاح الإجابة للمتصفح قبل السماح. |
| **C-15** | المدرس يضبط: التوقيت والمدة والمحاولات، وأعلى/آخر نتيجة، وإظهار الدرجة، وإتاحة المراجعة — كلًا على حدة. | إعدادات الامتحان كائن مستقل عن الأسئلة. |
| **C-16** | حماية متوازنة: لا كاميرا، ولا اتهام تلقائي؛ أحداث المغادرة **مؤشرات مراجعة**. | لا إنهاء تلقائي لمجرد فقدان التركيز. |
| **C-17** | التنبيهات **داخل المنصة فقط**. | لا واتساب/SMS/بريد مدفوع. |
| **C-18** | واجهة عربية RTL، بسيطة، متجاوبة، بأولوية موبايل في الحضور والامتحان. | كل شاشة تُصمَّم RTL أولًا. |
| **C-19** | الحزمة: HTML5 + CSS3 + Bootstrap 5 RTL + JS ES Modules، وخلفية Supabase (PostgreSQL + Auth + Storage + Edge Functions + RLS). لا Laravel/Inertia/React/Tailwind. | أي إطار/خدمة مدفوعة جديدة تحتاج موافقة صريحة. |
| **C-20** | خارج الإصدار الأول: المصاريف والدفع، الاشتراكات، المقالي، بوابة ولي الأمر، واتساب/SMS، البث، رفع الفيديو، الكاميرا، مدير سنتر مستقل، التطبيق الأصلي. | لا تُبنى جداول أو أزرار لهذه الميزات. |
| **C-21** | هدف الحمل ١٠٠–١٠٠٠ طالب متزامن **هدف اختبار وتصميم، لا ضمان سعة**. | يُقاس على بيئة محددة ويُوثَّق. |
| **C-22** | التصدير في الإصدار الأول **CSV** بحماية من صيغ الحقن. | Excel/PDF ليست مطلوبة. |
| **C-23** | الزمن على الخادم بـUTC ويُعرض بالمنطقة المعتمدة؛ ساعة الطالب ليست مرجعًا. | كل الحسابات على `timestamptz`. |
| **C-24** | الاستعادة تُبطل الجلسات القديمة وتُسجَّل باسم من نفّذها وسببها. | جدول رموز + جدول تدقيق. |
| **C-25** | كلمة المرور لا تظهر للمدرس ولا للإدارة. | لا مسار يقرأ كلمة مرور؛ التغيير فقط. |
| **C-26** | الترتيب داخل نطاق امتحان أو مجموعة يحددها المدرس، لا بين مدرسين. | لا لوحة ترتيب عامة. |
| **C-27** | **اسم المنصة: «مِنهاج»** — اعتمده العميل (A-01)، ولم يعد توصية. | يُستخدم في كل الشاشات والوثائق كاسم مؤقت قابل للتغيير. |
| **C-28** | **هوية الدخول = رقم الهاتف + كلمة مرور فقط.** أُلغي خيار «كود الطالب + كلمة مرور» كنوع دخول. | قرار العميل 2026-11-04 (A-05). **يعدّل §3 من وثيقة المتطلبات** التي كانت تتيح الكود بديلًا. `student_code` يبقى معرّفًا للعرض والبحث داخل مساحة المدرس، لا وسيلة دخول. |
