# ٠٤ — دليل تنفيذي: صلاحيات المساعدين (المهاجرة 0014)

**التاريخ:** ٢٠٢٦-١١-٠٦ · **القاعدة:** مشروع الاختبار (PG 17) · **البيانات:** اصطناعية داخل معاملة أُلغيت بالكامل (`rollback`)
**الغرض:** إثبات أن دوال 0014 تعمل وقت التشغيل فعلًا (إنشاء الدالة لا يتحقق من أسماء الأعمدة/القيم داخلها).

| # | الحالة | المتوقع | الناتج الفعلي |
|---|---|---|---|
| ١ | حفظ صلاحية `groups:read` على مجموعة تابعة للمدرس | نجاح | `{actions_count: 1}` ✅ |
| ٢ | حفظ نفس الصلاحية على **مجموعة مدرس آخر** | رفض | `42501 group-outside-workspace` ✅ |
| ٣ | فعل غير معروف `bogus:action` | رفض | `22023 unknown-action:bogus:action` ✅ |
| ٤ | سحب العضوية بلا سبب | رفض | `22023 reason-required` ✅ |
| ٥ | المساعد يقرأ مجموعته المصرَّح بها | `true` | `true` ✅ |
| ٦ | المساعد يقرأ مجموعة خارج نطاقه | `false` | `false` ✅ |
| ٧ | سحب بسبب ≥٥ أحرف | نجاح | `{status: revoked, changed: true}` ✅ |
| ٨ | القراءة بعد السحب (سريان فوري) | `false` | `false` ✅ |
| ٩ | إحياء عضوية مسحوبة | رفض | `22023 cannot-revive-revoked` ✅ |

**ما لم يُثبت بعد:** مسار الدعوة الكامل (`assistant_invite` → `assistant_accept`) لم يُنفَّذ وقت التشغيل؛ يحتاج مستخدمًا جديدًا في `auth.users`. يُغطَّى في اختبار SQL/e2e بالدفعة ٤.
