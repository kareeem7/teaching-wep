## 2. المقارنة البنيوية: استضافة اقتصادية مقابل خيار مُدار

| البعد | خيار اقتصادي (A) | خيار مُدار كامل (B) | ما نتأثر به فعلًا |
|---|---|---|---|
| الواجهة | استضافة ثابتة مجانية/رخيصة | نفس الشيء عمليًا | لا فرق جوهري: ملفات ثابتة فقط |
| قاعدة البيانات | Supabase (لا بديل مُدار في الحزمة المعتمدة) | Supabase بخطة أعلى | الاتصالات المتزامنة أثناء الامتحان |
| Auth | داخل Supabase | داخل Supabase | نفس المكوّن |
| Edge Functions | حدود طلبات ووقت CPU | حدود أعلى | **كل حفظ/تسليم يمر بها — أعلى مستهلك** |
| Storage | صور فقط | صور + مساحة أكبر | منخفض في الإصدار الأول (لا فيديو) |
| **نسخ خارجي** | `pg_dump` مجدول → تخزين كائنات خارجي (R2/S3) | PITR داخل Supabase + نسخ خارجي | **النسخ الخارجي إلزامي في الخيارين** |
| **مراقبة** | سجلات Supabase + مراقبة توافر خارجية | نفس الشيء بحدود أعلى | توافر الدوال أثناء الامتحانات |
| التوقف عند الخمول | ممكن (خطة مجانية) | لا | يمنع استخدام المجاني في الإنتاج |
| المخاطرة الأساسية | حدود الاتصالات/الدوال عند الذروة | تكلفة أعلى دون حاجة مثبتة | قرار الترقية يحتاج قياسًا |

**الترتيب الموصى به (D-128):**

1. **الآن:** بيئة محلية/Supabase محلي — صفر تكلفة، بلا أسرار، بلا بيانات حقيقية.
2. **staging:** خطة Supabase اقتصادية + استضافة ثابتة + **نسخ خارجي مجدول** + مراقبة توافر.
3. **إنتاج:** نفس الخيار الاقتصادي، مع نسخ خارجي مختبر (لا إطلاق قبل `RESTORE_TEST_REPORT.md`).
4. **ترقية:** فقط بعد `LOAD_TEST_REPORT.md` يُظهر حدًّا فعليًا على مواصفات محددة.

## 3. النسخ الخارجي والمراقبة (ليسا اختياريين)

| العنصر | الحد الأدنى الموصى به | التكلفة |
|---|---|---|
| نسخة قاعدة البيانات | `pg_dump` يومي مشفّر → تخزين كائنات مستقل عن خادم الإنتاج | خارج حدسي؛ تحتاج تسعيرًا |
| نسخة التخزين | مزامنة صور الدروس/المرفقات | نفس المصدر |
| احتفاظ | ٧ يومية + ٤ أسبوعية + ١٢ شهرية (مقترح، يحتاج اعتمادًا) | يتبع الحجم |
| اختبار استعادة | مرة قبل الإطلاق ومرة كل ربع | وقت بشري |
| مراقبة التوافر | فحص كل دقيقة لصفحة الدخول ودالة `exam-save` | خطة مجانية غالبًا تكفي |
| تنبيهات الأخطاء | سجل أخطاء الدوال + تنبيه | — |

**لا ادعاء:** حجم البيانات وأرقام RPO/RTO غير محسومة (D-202). النسخة اليومية وحدها تعني احتمال ضياع يوم كامل — وهذا يجب أن يعتمده المالك صراحةً.

## 4. ما استُبعد ولماذا

| البديل | سبب الاستبعاد |
|---|---|
| خادم VPS + Postgres مُدار يدويًا | يخالف الحزمة المعتمدة (لا خادم تطبيق تقليدي) ويزيد عبء التشغيل |
| Redis أو طابور خارجي | غير لازم؛ idempotency تُحقق بقيود قاعدة البيانات |
| مزود SMS/OTP | **مدفوع وممنوع** في الإصدار الأول؛ التصميم يتجنبه أصلًا (D-129) |
| استضافة فيديو | خارج النطاق؛ يوتيوب |
| خطة Supabase عليا الآن | لا شراء قبل قياس (D-022) |

## 5. عوامل التكلفة غير المالية

- وقت الإعداد والتشغيل والصيانة (بشري).
- كلفة الأخطاء: إعداد نسخ بلا اختبار استعادة = تكلفة مضاعفة عند الحادث.
- كلفة الفحص الأمني قبل الإطلاق (المرحلة ١١).
