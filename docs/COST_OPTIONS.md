# خيارات التكلفة — COST_OPTIONS

آخر تحديث: 2026-11-04 · المرحلة: 00 · **لا شراء ولا اشتراك ولا إنشاء مشروع في هذه المرحلة** (القاعدة 13/14).

> **تحذير على كل أرقام هذا الملف:** هي **ترتيب نسبي وأسئلة يجب التحقق منها**، وليست أسعارًا مسعّرة. لم يُفتح أي حساب مدفوع ولم تُطلب أي عروض. أي رقم مالي نهائي يجب أن يأتي من صفحة تسعير المزوّد وقت القرار ومن العميل، ويُسجَّل في `docs/DECISIONS.md`.

## 1. المكوّنات التي تحدد التكلفة

| المكوّن | ما يستهلكه المشروع فعليًا |
|---|---|
| استضافة الواجهة | ملفات ثابتة فقط، حركة منخفضة |
| مشروع Supabase | قاعدة البيانات + التخزين + الاستدعاءات + ساعات Edge Functions |
| Auth | مستخدمون نشطون (MAU) |
| Storage | صور الدروس ومرفقات الأسئلة فقط (لا فيديو) |
| Edge Functions | بدء/حفظ/تسليم/تصحيح — أعلى استهلاك وقت الامتحانات |
| المهام المجدولة | إغلاق المحاولات والتنبيهات |
| النسخ الاحتياطي | نسخ مشفرة + نقاط استعادة قبل الامتحانات |
| المراقبة | سجلات وأخطاء |

## 2. الخيارات

| الخيار | الواجهة | الخلفية | المزايا | القيود/المخاطر |
|---|---|---|---|---|
| **C1 — مجاني للتطوير فقط** | استضافة ثابتة مجانية | مشروع Supabase مجاني | صفر تكلفة، بداية سريعة | حدود صارمة، مشروع مجاني يُوقف عند الخمول، **غير مناسب للإنتاج** |
| **C2 — الاقتصادي (موصى به للبداية)** | استضافة ثابتة مجانية/رخيصة | Supabase مدفوع بأصغر خطة | استمرارية ونسخ احتياطي وحدود أعلى | يجب التحقق من حدود الاتصالات وسعة الحوسبة عند ١٠٠٠ طالب متزامن |
| **C3 — الأقوى** | نفس الواجهة | خطة أعلى + حوسبة إضافية | هامش أكبر للامتحانات المتزامنة | تكلفة أعلى دون حاجة مثبتة قبل القياس |

**التوصية:** C1 للتطوير والاختبارات الآن؛ C2 عند الانتقال إلى staging حقيقي؛ الترقية إلى C3 **فقط** بعد `LOAD_TEST_REPORT.md` يُظهر حدود C2 على مواصفات محددة. لا ترقية بناءً على تخمين.

## 3. أسئلة يجب حسمها قبل أي التزام مالي

1. ما سقف التكلفة الشهرية الذي يقبله المالك؟ (D-202 — مفتوح)
2. كم طالبًا فعليًا متوقعًا في أول ٦ أشهر؟ (الفرق بين ١٠٠ و١٠٠٠٠ يغيّر القرار)
3. هل نحتاج نقاط استعادة قبل كل امتحان؟ ما تكلفتها لكل نقطة؟
4. ما RPO/RTO المقبول؟ النسخة اليومية تعني احتمال ضياع يوم كامل.
5. هل يوجد نموذج دخل؟ غير محسوم في المتطلبات — لا يؤثر على القرار التقني الآن.
6. هل يوجد قيد دفع محلي (بطاقة دولارية/فواتير) في بلد التشغيل؟

## 4. ما نفعله بدون شراء (البديل المحلي)

- Supabase CLI محلي لتشغيل PostgreSQL وAuth وEdge Functions في التطوير.
- بيانات وهمية فقط (`seed.sql`) — لا بيانات طلاب حقيقية (القاعدة 5).
- اختبارات RLS تعمل محليًا بالكامل.
- قياس الحمل محليًا لتقدير أولي، ثم إعادة القياس على staging حقيقي قبل أي ادعاء سعة.

## 5. مخاطر التكلفة

| الخطر | الأثر | التخفيف |
|---|---|---|
| Edge Functions استُدعيت لكل حفظ إجابة | تكلفة غير خطية مع كل طالب | حفظ دوري مجمّع بفاصل معقول، لا حفظ لكل ضغطة |
| بيانات كثيرة في استجابة ضخمة | خروج بيانات (egress) أعلى | `select` محدد الأعمدة، ترقيم، ضغط |
| مشروع مجاني يتوقف | تعطّل بيئة اختبار | لا استخدامه إلا للتطوير، وتوثيق ذلك |
| نسخ احتياطي غير مختبر | لا قيمة فعلية للتكلفة | `RESTORE_TEST_REPORT.md` إلزامي |
