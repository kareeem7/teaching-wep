# فهرس أدلة فحص المرحلة ٠١

**تاريخ الإعداد:** 2026-11-04 · **الحالة:** لم يُجرَ فحص مستقل بعد · **لا حكم هنا**

> هذا الملف **فهرس أدلة** يخدم الفاحص، وليس حكمًا ولا اعتمادًا. الحكم يُكتب بعد الفحص في هذه الجولة نفسها.

## ١) ما يجب أن يفحصه المراجع

| # | البند | أين | المتوقع |
|---|---|---|---|
| 1 | المسارات الملزمة موجودة فعلًا وبأسمائها | `git ls-files` | ٢٣ مسارًا من قائمة المرحلة ٠١ كلها موجودة |
| 2 | لا ملفات فارغة | `find . -type f -empty` | صفر |
| 3 | لا كود ميت أو وهمي | مراجعة `public/assets/js/` | كل دالة مستخدمة أو مُصدَّرة لغرض واضح |
| 4 | رفض المفاتيح السرّية | `public/assets/js/config.js` + ١٨ اختبار | `service_role` و`sb_secret_` مرفوضان |
| 5 | `public/` بلا أسرار | خطوة CI + فحص محلي | لا مفاتيح ولا JWT |
| 6 | الصفحة الشكلية لا تدّعي عملًا | `pages/auth/login.html` | كل الحقول والزر معطّلة + تنبيه صريح |
| 7 | التغطية بـRTL | كل صفحة | `lang="ar"` و`dir="rtl"` |
| 8 | لا وظائف أكاديمية | الشجرة | لا مسار طلاب/درجات/امتحانات |
| 9 | الهوية مطابقة للقرار C-29 | `app.css` §١ | قيم `#0b3b5a` و`#c98a1b` و`#f7f5f0` |
| 10 | CI حقيقي | `.github/workflows/ci.yml` | ٣ وظائف/خطوات: lint، وحدة، متصفح، فحص أسرار |

## ٢) الأدلة المحفوظة

| الملف | المحتوى |
|---|---|
| `docs/test-artifacts/commands-local.log` | مخرجات ESLint وStylelint وHTMLHint واختبارات الوحدة بأكواد الخروج |
| `docs/test-artifacts/http-smoke.txt` | ١١ مسارًا عبر HTTP مع الأحجام وعلامات RTL |
| `docs/test-artifacts/e2e-local-attempt.log` | فشل تنزيل Chromium وفشل التشغيل المحلي (BLOCKED) |

## ٣) ما لا يوجد هنا (بصراحة)

- **لا نتائج Playwright محلية** — البيئة تحجب تنزيل المتصفح.
- **لا قاعدة بيانات** — المهاجرة لم تُطبَّق.
- **لا لقطات شاشة** — لا متصفح في البيئة؛ الصفحات متاحة للمعاينة على المنفذ ٤١٧٣ أثناء الجلسة.
- **لا فحص وصول آلي كامل** — فحص أساسي فقط (تباين الألوان محددة في الرموز، حلقات تركيز، تخطي للمحتوى).

## ٤) كيف يعيد المراجع إنتاج النتائج

```bash
npm ci
npm run lint          # ESLint + Stylelint + HTMLHint
npm run test:unit     # 18/18
npm run serve &       # ثم افتح /index.html و /pages/health.html
npx playwright install --with-deps chromium && npm run test:e2e   # يحتاج شبكة غير محجوبة
```
