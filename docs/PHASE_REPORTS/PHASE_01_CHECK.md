وهذا الاختبار لم يُنفَّذ هنا. ما نُفِّذ بديلًا (jsdom + HTTP + lint) حقيقي، لكنه لا يساوي E2E، ولن أدّعي معادلته.

## ٣) اختبارات E2E — مكتوبة، غير مُشغَّلة

`tests/e2e/smoke.spec.js` يحتوي **١١ اختبارًا × مشروعان (سطح مكتب Chromium + Pixel 5) = ٢٢ حالة**:
تحميل الصفحة بالعربية RTL · بناء الشريط وثلاثة روابط · انعدام أي طلب CDN · صفر أخطاء JavaScript ·
فحص الحالة ينتهي بحالة نهائية · نموذج الدخول معطّل ولا يُرسل · عرض `next` · تحويل الرابط المحمي إلى الدخول ·
ثلاث صفحات أخطاء.

**هذه حالات غير مُنفَّذة، ولا يجوز احتسابها ناجحة.** ستُشغَّل في CI عبر
`npx playwright install --with-deps chromium` ثم `npm run test:e2e`.

## ٤) قاعدة البيانات — تحقق فعلي

| الفحص | الوسيلة | النتيجة |
|---|---|---|
| المهاجرتان مُطبَّقتان بالترتيب | `supabase_migrations.schema_migrations` | `0001_extensions` ثم `0002_platform_meta` ✅ |
| `public.platform_meta` موجود | `pg_class` + `pg_namespace` | ✅ |
| RLS مفعّلة | `relrowsecurity` | `true` ✅ |
| عدد السياسات | `pg_policy` | ١ سياسة `SELECT` فقط ✅ |
| صفر سياسة كتابة | `pg_policies` | ✅ (لا INSERT/UPDATE/DELETE) |
| الامتدادات | `pg_extension` | `pgcrypto` · `citext` · `pg_trgm` في `extensions` ✅ |
| الصفوف | `select` | ٤ صفوف إعدادات عرض فقط ✅ |
| لا جدول أشخاص | فحص `information_schema.tables` | صفر جدول طلاب/مدرّسين ✅ |

**غير مُتحقق:** قراءة `anon` من REST. `curl https://wdqupfoznngqbyphjnie.supabase.co` من بيئة التنفيذ يرجع `000`
(شبكة محجوبة). السياسة مكتوبة ومُثبَتة على مستوى القاعدة، لكن إثباتها من المتصفح مطلوب في CI أو جهاز المطوّر.

## ٧) ما أطلبه من الفاحص

1. تشغيل `npm ci && npm run check` على جهاز فيه متصفحات Playwright.
2. نداء `GET /rest/v1/platform_meta?select=key,value` بمفتاح publishable — يجب أن يرجع ٤ صفوف.
3. محاولة `POST/PATCH` بالمفتاح نفسه — يجب أن تُرفض.
4. البحث يدويًا عن أي سر في `public/`.
5. اختبار الصفحات على عرض جوال حقيقي، لا محاكاة فقط.

**لن أبدأ المرحلة ٠٢، ولن أُعلن نجاحًا لم يُشغَّل.**
