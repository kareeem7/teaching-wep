## ٢. ما نُفِّذ فعلًا حتى الآن

### المهاجرة `0012_locations_groups.sql` — مطبَّقة ومتحقَّق منها

| المخرج | التفصيل |
|---|---|
| `public.locations` | مكان لكل مدرس، تفرّد الاسم **داخل المساحة فقط** (`teacher_id, lower(name)`) ⇒ تشابه الاسم عند مدرسين لا يدمج شيئًا |
| `public.subjects` | مادة لكل مدرس، نفس قاعدة التفرّد |
| `public.grades` | الصف الدراسي + `sort_order` |
| `public.groups` | أعمدة `location_id` · `subject_id` · `grade_id` بمفاتيح أجنبية **مركّبة** `(id, teacher_id)` ⇒ يستحيل ربط مجموعة بكيان مدرس آخر حتى لو حاول أحدهم تمرير معرّف من الخارج |
| `public.schedule_slots` | مواعيد أسبوعية (٠=السبت)، تحقّق `ends_at > starts_at`، فرادة `(group_id, weekday, starts_at)` |
| حارس المكان | مُشغِّل يرفض `42501` أي موعد يشير إلى مكان خارج مساحة المجموعة |
| نقل البيانات | الأعمدة النصية القديمة تُترجم مرة واحدة إلى كيانات (لا حذف، لا فقد) |
| الأمان | RLS مُفعَّلة على الأربعة **بلا سياسات** ⇒ أي تطبيق جزئي يمنع الجميع بدل أن يفتح للجميع؛ السياسات في `0015` |

### المهاجرة `0013_students_profiles.sql` — مطبَّقة ومتحقَّق منها

| المخرج | التفصيل |
|---|---|
| حقول الطالب | `phone_e164` (رقم مستقل) · `grade_id` مرتبط بصفوف نفس المساحة (مُشغِّل يرفض غير ذلك) |
| قيد الاتصال | لا طالب بلا رقم مستقل **أو** رقم ولي أمر (`not valid` على القديم، يُتحقق الجديد فورًا) |
| تنبيه التكرار | `app.student_duplicate_hints()` تُرجع مرشّحين بأسباب `same_phone` / `same_guardian_phone` / `similar_name` — **بلا دمج تلقائي** |
| التسجيل المحلي | `app.student_register_local()`: تحقّق اسم/كود/هاتف/ولي أمر/ملاحظات/صف، وفرادة الكود داخل المساحة، وإرجاع المرشّحين |
| دعوة الربط | `app.student_create_link_invitation()`: رمز مبصوم `^[0-9a-f]{64}$`، صلاحية ١–١٦٨ ساعة، إبطال الدعوة السارية قبل إنشاء جديدة، ورفض دعوة طالب مرتبط |
| الغلاف الخدمي | `public.svc_student_register` · `public.svc_student_link_invitation` — `service_role` فقط، مسحوبة من `public/anon/authenticated` |
