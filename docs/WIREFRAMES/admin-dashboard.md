# نموذج شاشة — لوحة السوبر أدمن

**المرحلة:** ٠٣ · **الدور:** سوبر أدمن · **الأولوية:** كمبيوتر أولًا، تعمل على الموبايل
**الحالة:** تصميم منخفض الدقة للنقاش — لا كود.

## الهدف
متابعة حسابات المدرسين ونشاط المنصة، والاطلاع الأكاديمي **للقراءة فقط** (C-04).

## التخطيط

```text
┌──────────────────────────────────────────────────────────────┐
│ مِنهاج        [لوحة الإدارة]   [المدرسون] [التعليمات]   (اسم)│
├──────────────────────────────────────────────────────────────┤
│  نظرة عامة — آخر ٣٠ يومًا                        [تحديث ⟳]  │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐        │
│ │ مدرسون   │ │ نشطاء    │ │ طلاب     │ │ محاولات  │        │
│ │   ١٢     │ │   ٩      │ │  ٤٣٧     │ │  ١٢٨٤    │        │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘        │
│                                                              │
│ آخر النشاط                                                  │
│ ┌──────────────────────────────────────────────────────────┐│
│ │ مدرس X · تفعيل حساب        · منذ ساعتين                  ││
│ │ مدرس Y · ٤٢ محاولة اليوم   · منذ ٥ ساعات                 ││
│ └──────────────────────────────────────────────────────────┘│
│                                                              │
│ تنبيه: هذه الشاشة لا تسمح بتعديل الحضور أو الدرجات.        │
└──────────────────────────────────────────────────────────────┘
```

## العناصر والقرارات
| العنصر | السلوك | ملاحظة |
|---|---|---|
| بطاقات الأرقام | عدد المدرسين، الحسابات النشطة، الطلاب الفريدون، المحاولات | أرقام قابلة للتتبع إلى سجلات مصدرها |
| آخر النشاط | أحداث إدارية فقط (تفعيل، إيقاف، دعوة) | لا يُعرض محتوى أكاديمي حساس |
| شريط تنبيه ثابت | تذكير أن الإدارة للقراءة فقط | يقلل محاولات الوصول غير المصرح |
| زر «المدرسون» | ينتقل لصفحة القائمة | — |

## الحالات
- **فارغ:** «لا يوجد مدرسون بعد — ابدأ بدعوة أول مدرس.» + زر الدعوة.
- **تحميل:** هياكل عظمية للبطاقات (skeleton) لا دوّارة وسط الشاشة.
- **خطأ:** «تعذّر تحميل الأرقام» + إعادة المحاولة + وقت آخر تحديث ناجح.
- **انقطاع:** شريط أعلى «أنت غير متصل — الأرقام قد تكون قديمة».

## الصلاحيات
قراءة فقط لكل ما هنا. أي محاولة كتابة أكاديمية تُرفض على الخادم حتى لو أُرسلت يدويًا.

## RTL والوصول
- كل الأرقام بأرقام عربية-هندية أو لاتينية؟ **قرار:** لاتينية للتواريخ والعدادات الكبيرة (أوضح)، عربية-هندية داخل نصوص الطلاب. (تفصيل يُثبَّت في المرحلة ٠١.)
- التباين AA، والتنقل بلوحة المفاتيح كامل، والبطاقات ليست روابط وهمية.

## مؤجل
مخططات بيانية متقدمة · مقارنات زمنية · تصدير شامل (O-05) · إدارة صلاحيات إدارية متعددة.
