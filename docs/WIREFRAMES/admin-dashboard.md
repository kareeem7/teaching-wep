# نموذج شاشة — لوحة السوبر أدمن

المرحلة: 03 · الصفحة: `public/pages/admin/dashboard.html` · السكربت: `public/assets/js/admin/dashboard.js`
المتطلبات: REQ-01، REQ-03، REQ-16، REQ-17

## الغرض

نقطة دخول السوبر أدمن: حالة المدرسين، الاستخدام العام، والتعليمات. **قراءة فقط للبيانات الأكاديمية.**

## المستخدم

سوبر أدمن فقط. أي دور آخر يُحوَّل إلى 403.

## المكوّنات

| المكوّن | المصدر | ملاحظة |
|---|---|---|
| بطاقات الأرقام | استعلام إحصائي على الخادم | أرقام قابلة للتتبع إلى سجلات مصدرها (REQ-15) |
| جدول المدرسين | `teacher_workspaces` + إحصاء | ترقيم إلزامي، بحث بالاسم |
| رابط «تفاصيل» | `teacher-detail.html` | قراءة فقط |
| التنبيهات | `notifications` | حالة مقروء/غير مقروء |
| التعليمات | `admin-instructions` | إنشاء تعليمات (كتابة إدارية مسموحة) |

## ما لا يظهر إطلاقًا

- زر تعديل حضور أو درجة أو إجابة.
- أي إجراء «باسم المدرس».
- أي مفتاح إجابة أو محتوى محاولة طالب.

## الحالات

| الحالة | العرض |
|---|---|
| تحميل | هياكل عظمية (skeletons) للبطاقات والجدول |
| فارغ | «لا يوجد مدرسون بعد» + زر دعوة |
| خطأ | رسالة + إعادة محاولة، بلا كشف تفاصيل داخلية |
| لا صلاحية | تحويل إلى `errors/403.html` |

## RTL وإتاحة

- `dir="rtl" lang="ar"`، الأرقام تُعرض باتجاه LTR داخل الخلية.
- الأزرار قابلة للوصول بلوحة المفاتيح، وكل حالة لها نص لا لون فقط.

## معايير القبول

1. السوبر أدمن لا يستطيع تعديل أي بيانات أكاديمية من هذه الشاشة (ISO-08).
2. الأرقام مطابقة للاستعلام المعلن عنها في التقرير.
3. لا تظهر بيانات طالب فردية بلا مسار قراءة مسجّل.
