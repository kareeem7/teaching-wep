# نموذج شاشة — نتائج الطالب

**المرحلة:** ٠٩ (+١٠ للتقارير) · **الأدوار:** طالب (نتائجه) · مدرس (نطاقه) · **الأولوية:** موبايل

## الهدف
عرض نتيجة الطالب ونتائجه السابقة بصدق، مع احترام إعدادات الإتاحة.

## التخطيط — نتيجة محاولة
```text
┌────────────────────────────────────┐
│ امتحان الجبر ٢                     │
│          ٨ / ١٠   (٨٠٪)            │
│ محاولة ٢ من ٣ — محتسبة: الأعلى     │
│ تم التسليم: ٧:٤١ م                  │
├────────────────────────────────────┤
│ [مراجعة الإجابات]  ← حسب إعداد     │
└────────────────────────────────────┘
```

## التخطيط — سجل النتائج
```text
┌──────────────────────────────────────────────┐
│ نتائجي                                       │
│ الامتحان      │ المحاولة │ الدرجة │ الحالة   │
│ الجبر ٢       │ ٢/٣      │ ٨/١٠  │ منشورة   │
│ التفاضل ١     │ ١/٣      │ ٦/١٠  │ منشورة   │
│ الهندسة       │ —        │ —     │ بانتظار  │
└──────────────────────────────────────────────┘
```

## قواعد إلزامية
| القاعدة | المرجع |
|---|---|
| لا تظهر الدرجة قبل `released` | C-15 |
| المراجعة والشرح إعداد مستقل عن إظهار الدرجة | C-15 |
| الطالب يرى درجاته فقط، ولا يرى ترتيب زملائه افتراضيًا | C-26 / O-04 |
| «لم يُجب» ≠ «محاولة ملغاة» — يجب تمييزهما بنص صريح | REQ-14 |
| المتوسط بالنسبة المئوية مع ذكر عدد الامتحانات | REQ-15 |
| عند وجود عدة محاولات يظهر أيها محتسبة ولماذا | C-15 |

## حالات
- **نتيجة قيد النشر:** «لم تُنشر النتيجة بعد». لا درجة ولا تلميح.
- **مراجعة غير متاحة:** زر معطّل بسبب مكتوب: «المراجعة تُتاح بعد إغلاق الامتحان».
- **بدون نتائج:** حالة فارغة إرشادية.
- **خطأ في التصحيح:** «جاري مراجعة درجتك» إن أُعيد الاحتساب.

## عرض للمدرس
نفس الشاشة بنطاق أوسع: توزيع الدرجات، المحاولات، الطلاب المتعثرين — مع تصدير CSV (سياسة).

## RTL والوصول
الشريط التقدمي يحمل قيمة نصية أيضًا (٨٠٪) وليس لونًا فقط.
