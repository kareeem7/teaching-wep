# نموذج شاشة — نتائج الطالب

المرحلة: 09 · الصفحات: `student/exam-result.html`, `student/review.html` · السكربت: `exam-result.js`, `review.js`
المتطلبات: REQ-14، REQ-15، REQ-18

## الغرض

عرض درجة الطالب في امتحان وفق إعداد الإفراج، ومراجعة الإجابات فقط عند السماح.

## 1. صفحة النتيجة

```
┌──────────────────────────────────────┐
│ ← نتيجة: التفاضل                     │
├──────────────────────────────────────┤
│              ٨ / ١٠                  │
│              ٨٠٪                     │
│                                       │
│ المحاولة: الأولى من ١                │
│ الاحتساب: الأعلى                     │
│ وقت التسليم: ٧:٤٢ م                  │
├──────────────────────────────────────┤
│ [مراجعة الإجابات]  ← يظهر فقط إن سُمح │
│                                       │
│ ملاحظة: هذا الامتحان بلا ترتيب بين    │
│ الزملاء.                              │
└──────────────────────────────────────┘
```

## قواعد العرض

| الحالة | ما يراه الطالب |
|---|---|
| «فور التسليم» | الدرجة مباشرة |
| «بعد الإغلاق» | «سيظهر بعد انتهاء الامتحان» + الموعد |
| «بعد نشر المدرس» | «لم تُنشر النتيجة بعد» |
| مراجعة ممنوعة | لا زر مراجعة، ولا رابط مباشر يعمل |
| مراجعة مسموحة | الإجابات والشرح وفق الإعداد |

- تُعرض **الدرجة والنسبة** دائمًا معًا، وطريقة احتساب المحاولة.
- عند تعدد المحاولات: النتيجة المعروضة تتبع السياسة (الأعلى/الأخيرة) ويُوضَّح ذلك نصًّا.
- لا يُعرض ترتيب الطالب بين زملائه افتراضيًا (REQ-15).
- الطالب يرى درجاته هو فقط (ISO-06).

## 2. صفحة المراجعة

```
┌ مراجعة الإجابات ─────────────────────┐
│ سؤال ١ ✓ صحيح                        │
│ مشتقة x² هي...                        │
│ إجابتك: 2x ✓    الصحيحة: 2x           │
│ الشرح: ...                            │
├──────────────────────────────────────┤
│ سؤال ٢ ✗ خطأ                          │
│ إجابتك: x      الصحيحة: 2             │
└──────────────────────────────────────┘
```

- علامة الصح/الخطأ **نصية + أيقونة**، لا لون فقط.
- السؤال غير المجاب يظهر «لم تُجب» — ويختلف عن الخطأ.
- لا تُعرض إجابات صحيحة قبل السماح، ولو عبر طلب شبكة مباشر (ISO-07).

## تصحيح مفاتيح الإجابة

إن صحّح المدرس مفتاحًا:
- تُعاد احتساب النتائج، ويُسجَّل التغيير قبل/بعد/سبب.
- يظهر للطالب إشعار «تم تحديث نتيجتك» مع الوقت، دون كشف إجابات لم تُسمح.

## الصلاحيات

- الطالب: نتيجة محاولته فقط، عبر RLS.
- لا مسار لقراءة نتيجة زميل بمعرّف.
- المساعد: `grades.read` داخل نطاقه فقط.

## الحالات

| الحالة | العرض |
|---|---|
| محاولة لم تبدأ | «لم تبدأ هذا الامتحان» + زر بدء إن كان متاحًا |
| محاولة ملغاة إداريًا | حالة مستقلة وواضحة، لا تُعرض كصفر |
| بلا نتائج | «لا نتائج بعد» |
| خطأ شبكة | إعادة محاولة بلا فقدان السياق |

## RTL وإتاحة

- الكسر «٨ / ١٠» و«٨٠٪» يُعرضان باتجاه مفهوم داخل RTL.
- كل معلومة رقمية مصحوبة بتسمية نصية.
- التباين كافٍ في حالات النجاح/الرسوب دون الاعتماد على الأخضر/الأحمر وحدهما.

## معايير القبول

1. لا ظهور لدرجة قبل موعد الإفراج (T-REQ-14-04).
2. المراجعة غير قابلة للوصول برابط مباشر عند منعها.
3. النتيجة مطابقة لملف الطالب وتقرير المدرس (سيناريو §17-14).
4. تصحيح مفتاح يُظهر أثرًا مسجّلًا لا تعديلًا صامتًا.
