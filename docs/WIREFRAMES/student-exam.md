# نموذج شاشة — غرفة الامتحان (الطالب)

**المرحلة:** ٠٩ · **الدور:** طالب · **الأولوية:** موبايل أولًا — أكثر شاشة حساسة في المنصة

## الهدف
السماح للطالب بالإجابة دون ارتباك، مع وقت وحفظ مرجعهما الخادم.

## التخطيط — قبل البدء
```text
┌────────────────────────────────────┐
│ امتحان الجبر ٢                    │
│ ١٠ أسئلة · ٣٠ دقيقة · محاولة ١ من ٣│
│ يغلق: ٨:٠٠ م                       │
│                                    │
│ • الوقت يبدأ عند الضغط على «ابدأ»  │
│ • لا يمكن إيقاف المؤقت             │
│ • انقطاع الاتصال لا يمدد الوقت     │
│                                    │
│        [ ابدأ الامتحان ]           │
└────────────────────────────────────┘
```

## التخطيط — أثناء المحاولة
```text
┌────────────────────────────────────┐
│ ⏱ ١٨:٤٢ متبقٍ      [تم الحفظ ✓]   │
│ سؤال ٣ من ١٠                       │
├────────────────────────────────────┤
│ نص السؤال…                         │
│ (•) أ                              │
│ ( ) ب                              │
│ ( ) ج                              │
│ ( ) د                              │
├────────────────────────────────────┤
│ [السابق]        [٣][٤][٥]…  [التالي]│
│         [تسليم الامتحان]           │
└────────────────────────────────────┘
```

## قواعد إلزامية
| القاعدة | المرجع |
|---|---|
| الوقت من الخادم؛ التحديث أو الانقطاع لا يعيد الوقت ولا ينشئ محاولة | C-14 |
| «تم الحفظ ✓» لا يظهر إلا بعد تأكيد الخادم | REQ-12 |
| لا يُرسل مفتاح الإجابة إلى المتصفح قبل السماح | C-14 |
| التسليم ذرّي وآمن من التكرار (نقرتان = تسليم واحد) | REQ-12 |
| انتهاء الوقت يغلق المحاولة تلقائيًا، وأي وصول لاحق يتحقق من الانتهاء | REQ-12 |
| مغادرة الصفحة تُسجَّل كحدث، **ولا تُنهي الامتحان** | C-16 |
| ملء الشاشة عند الدعم مع بديل واضح | C-16 |

## الحالات
- **انقطاع:** شريط «انقطع الاتصال — إجاباتك المحفوظة على الخادم حتى آخر لحظة» + إعادة اتصال تلقائية + **المؤقت لا يتوقف**.
- **محاولة منتهية:** توجيه لصفحة النتيجة/الرسالة بلا إمكانية إجابة.
- **محاولة نشطة من جهاز آخر (R-18):** «فتحت المحاولة في جهاز آخر — الكتابة من هنا ستُبطل حفظ الجهاز الآخر» مع حدث مسجّل، بلا إنهاء تلقائي.
- **تجاوز المحاولات:** «استنفدت محاولاتك (٣/٣)» + زر «تواصل مع مدرسك».
- **لم يبدأ الوقت بعد:** عدّ تنازلي لموعد الفتح، بلا زر.

## RTL والوصول
- الاختيارات أزرار كبيرة، وتباين عالٍ، وحالة التركيز واضحة.
- لا إعلانات ولا عناصر مشتتة؛ شريط التنقل مخفي أثناء المحاولة.

## حدود معلنة
لا كاميرا، ولا منع لفتح هاتف آخر، ولا كشف لتصوير الشاشة — الأحداث مؤشرات مراجعة فقط.
