# نموذج شاشة — غرفة الامتحان للطالب

المرحلة: 09 · الصفحة: `public/pages/student/exam-room.html` · السكربت: `public/assets/js/student/exam-room.js`
المتطلبات: REQ-12، REQ-13، REQ-18

## الغرض

حل امتحان بنسخة ثابتة، بمؤقت خادم، وحفظ تلقائي صادق، بلا إعادة وقت عند الانقطاع.


## شريط الحالة (إلزامي)

| المؤشر | المعنى | عند الفشل |
|---|---|---|
| ● متصل | آخر طلب خادم ناجح | «غير متصل — إجاباتك لن تُحفظ» |
| محفوظ 12:31 | وقت تأكيد الخادم للحفظ | «جارٍ الحفظ» / «لم يُحفظ» بلون ونص |
| ⏱ | الوقت المتبقي من وقت الخادم | لا يُوقف عند فقدان الاتصال |

**قاعدة الصدق:** «تم الحفظ» لا تظهر إلا بعد استجابة خادم. الحفظ المحلي ليس دليل حفظ.

## قواعد المحرك (من §10)

1. النسخة تُثبت عند أول بدء فقط (`exam-start`).
2. تحديث الصفحة أو انقطاع الاتصال: نفس الأسئلة، نفس الوقت المتبقي، **لا محاولة جديدة**.
3. المؤقت مرجعه الخادم (`server-time.js`)؛ ساعة الجهاز لا تُصدَّق.
4. نهاية المحاولة = الأقرب بين نهاية المدة وإغلاق الامتحان.
5. إجابة تصل بعد `expires_at` تُرفض ولو ظنّ المتصفح قبلها.
6. التسليم idempotent: تكرار الضغط لا يُنشئ نتيجتين.
7. جهاز واحد يكتب (`attempt_write_leases`): فتح من جهاز ثانٍ يُسجَّل ويبطل كتابة الأول، بلا محاولة إضافية.
8. الأحداث (مغادرة/عودة/خروج من ملء الشاشة) تُسجَّل كindicators ولا تُنهي الامتحان.

## ملء الشاشة

- عند التفعيل: زر «ابدأ» يطلب ملء الشاشة (يتطلب تفاعل مستخدم).
- عند الرفض أو عدم الدعم: **بديل واضح** — شريط تنبيه + استمرار الحل، لا تعطيل.
- الخروج ليس اتهامًا ولا إنهاء.

## ما لا يوجد في هذه الشاشة

- لا عرض لعدد صحيح الإجابات، ولا مفتاح إجابة، ولا مؤشر أداء لحظي.
- لا إعلانات ولا عناصر تنقل خارج الامتحان.
- لا كاميرا ولا ميكروفون ولا تسجيل شاشة.
- لا زر «إنهاء» يُنفّذ بسبب مغادرة الصفحة.

## الصلاحيات

- الطالب المسجل في المجموعة المستهدفة فقط.
- خارج الوقت أو خارج المحاولات المسموحة: 403/409 برسالة محددة.
- محاولة مسلَّمة سابقًا: لا شاشة حل، بل رابط النتيجة.

## الحالات

| الحالة | العرض |
|---|---|
| قبل البدء | شاشة تعليمات: المدة، عدد الأسئلة، «لا يمكن إيقاف المؤقت» |
| انقطاع اتصال | تعطيل خيارات مؤقتة؟ لا — استمرار الكتابة مع تحذير، وإعادة إرسال عند العودة |
| انتهاء الوقت | إغلاق تلقائي + شاشة «انتهى الوقت وتم التسليم» |
| محاولة ملغاة إداريًا | رسالة واضحة، مختلفة عن «غادرت» و«لم تبدأ» |
| جهاز ثانٍ | تنبيه «المحاولة مفتوحة على جهاز آخر» مع مسار آمن |

## RTL وإتاحة

- أسئلة عربية RTL؛ المعادلات LTR داخلها.
- خيارات كبيرة اللمس، وعلامة اختيار + نص («محدد») لا لون فقط.
- تنقل بلوحة المفاتيح بين السؤال والاختيارات.
- بلا تمرير أفقي على ٣٦٠px.
- لا مؤقت يومض أو يُحدث قلقًا بصريًا زائدًا؛ تحذير نصي عند آخر ٥ دقائق.
