# نموذج شاشة — لوحة المدرس

**المرحلة:** ٠٤ (تُهيَّأ في ٠١/٠٣) · **الدور:** مدرس (+ مساعد بصلاحياته)
**الحالة:** تصميم منخفض الدقة.

## الهدف
نقطة انطلاق يومية: ما يحتاج انتباه المدرس الآن، لا لوحة أرقام للزينة.

## العناصر
| العنصر | المصدر | قاعدة العرض |
|---|---|---|
| بطاقة «التالي» | أقرب حصة لم تنتهِ | إن لا حصص: «لا حصص قادمة» |
| «حضور غير مسجَّل» | حصص مضت بلا حالات | **ليس غيابًا** — تنبيه للمدرس فقط (C-10) |
| امتحانات نشطة | امتحانات `open` | تعرض المحاولات المسلّمة/المتاحة |
| «طلاب يحتاجون متابعة» | قواعد صريحة (غياب متكرر، متوسط منخفض) | تُكتب القواعد تحت القسم بشفافية |
| روابط سريعة | الحضور، الطلاب، الأسئلة | حسب صلاحية المساعد |

## حالات
- **مدرس جديد بلا بيانات:** حالة فارغة إرشادية: «أضف مجموعتك الأولى ثم سجّل طلابك» + خطوتان.
- **مساعد:** يرى فقط بطاقات الأفعال الممنوحة ونطاق مجموعاته، وبلا «إدارة المساعدين».
- **فارغ لكل قسم:** نص قصير + إجراء واحد.
- **خطأ:** بطاقة القسم تفشل وحدها، لا الشاشة كلها.

## الصلاحيات
المساعد بلا صلاحية حضور لا يرى بطاقة الحضور أصلًا — لكن الإخفاء ليس الحماية: طلب البيانات يُرفض خادميًا.

## RTL والموبايل
ترتيب البطاقات عمودي على الموبايل؛ الأزرار بحجم لمس ≥ ٤٤px؛ الأرقام والتواريخ بعرض مناسب.

## مؤجل
رسوم بيانية زمنية · تذكيرات خارج المنصة.
