## الغرض

ملخص يوم المدرس: حصص اليوم، الحضور الناقص، امتحانات نشطة، وطلاب يحتاجون متابعة.

### الشريط الجانبي حسب الدور (إلزامي — يغلق X-05)

الرسم أعلاه يمثّل **دور المدرس**. لا يُعاد استخدامه للمساعد كما هو:

| عنصر الشريط | مدرس | مساعد | شرط الظهور للمساعد |
|---|---|---|---|
| لوحتي | ✓ | ✓ | — |
| الطلاب | ✓ | ✓ | `students.read` |
| المجموعات | ✓ | ✓ | واحدة على الأقل داخل نطاقه |
| الحضور | ✓ | ✓ | `attendance.read` أو `attendance.write` |
| الدروس | ✓ | ✓ | `lessons.manage` (تحرير) وإلا قراءة فقط |
| الأسئلة | ✓ | ✓ | `questions.manage` |
| الامتحانات | ✓ | ✓ | `exams.manage` |
| التقارير | ✓ | ✓ | `reports.read` |
| **المساعدون** | ✓ | **✗ لا يظهر إطلاقًا** | — |
| **إعدادات المساحة** | ✓ | **✗ لا يظهر إطلاقًا** | — |
| **بنك الاستعادة/كلمات مرور الطلاب** | ✓ | **✗ لا يظهر إطلاقًا** | — |

**قاعدتان:** (١) العنصر الممنوع **لا يُعرض**، ولا يُعرض معطّلًا — لأن التعطيل يوحي بأنه قابل للتفعيل. (٢) إخفاء العنصر تجربة استخدام فقط؛ الرفض الحقيقي على الخادم (T-REQ-06-03).

## المكوّنات

| المكوّن | السلوك |
|---|---|
| بطاقة حصة | تعرض المجموعة والوقت وعدد الطلاب؛ الإجراء «رصد الحضور» يفتح `attendance-sheet.html?session=` |
| «لم تُرصد» | **ليس غيابًا** — بادج محايد بنص، لا لون أحمر |
| يحتاجون متابعة | معايير معلنة (غياب متتالٍ، نسبة منخفضة) قابلة للتفسير، لا صندوق أسود |
| امتحانات نشطة | الحالة: لم يبدأ / جارٍ / منتهٍ / بانتظار النشر |
| التنبيهات | تعليمات الإدارة + أحداث |

## الصلاحيات

- المدرس: كل ما في مساحته.
- المساعد: يرى فقط المجموعات في نطاقه، وبلا بطاقات تخص مجموعات أخرى (لا تظهر معطّلة، لا تظهر أصلًا).

## الحالات

| الحالة | العرض |
|---|---|
| لا مجموعات | «أنشئ أول مجموعة» + رابط |
| لا حصص اليوم | «لا حصص اليوم» + رابط الحصص القادمة |
| تعذّر تحميل جزء | البطاقة تعرض خطأ محليًا، وباقي اللوحة يعمل |

## RTL وإتاحة

- موبايل أولًا للبطاقات (عمود واحد تحت ٧٦٨px).
- أرقام المجموعات LTR داخل نص عربي.
- كل إجراء نصّي لا أيقونة وحيدة.

## معايير القبول

1. المساعد لا يرى أي رقم عن مجموعة خارج نطاقه (ISO-03/04).
2. «لم تُرصد» لا تُحتسب غيابًا في أي بطاقة.
3. كل رقم في اللوحة يمكن تتبعه إلى مصدره في التقارير.
