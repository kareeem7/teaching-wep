# نموذج شاشة — الطلاب والأماكن والمجموعات

**المرحلة:** ٠٤ · **الدور:** مدرس / مساعد (نطاق) · **الأولوية:** كمبيوتر للإدخال، موبايل للبحث السريع

## الهدف
إدارة ملفات الطلاب ومجموعاتهم دون خلط بين المدرسِين، ودون كشف حسابات الآخرين بالبحث.

## قرارات تصميم ملزمة
| القرار | السبب |
|---|---|
| البحث **داخل مساحة المدرس فقط** | C-02 — لا كشف حسابات مدرسين آخرين |
| «إجمالي فريد» بجانب العدد | C-03/REQ-04: الطالب في عدة مجموعات يُحسب مرة |
| إضافة طالب = ملف محلي + **دعوة ربط** | C-08 — لا ربط تلقائي |
| **الهاتف إلزامي لإنشاء حساب دخول** (C-28) | الهاتف هو وسيلة الدخول الوحيدة؛ الملف بلا رقم يبقى «بلا وصول» حتى يُضاف رقم |
| لا دمج تلقائي بالهاتف | منع ضم حسابين خطأً |
| كود الطالب للعرض والبحث فقط | C-28 — لا يُستخدم للدخول |
| نقل بين المجموعات يحفظ التاريخ | REQ-04 |

## الحالات
- **فارغ:** «لا طلاب بعد — أضف أول طالب أو استورد من مجموعة.» (الاستيراد مؤجل — لا زر وهمي.)
- **بحث بلا نتائج:** «لا نتائج لـ«…» — جرّب الكود أو الاسم الأول.»
- **تكرار محتمل:** لافتة «قد يكون هذا الطالب موجودًا (تشابه اسم/هاتف)» مع **مراجعة يدوية**، بلا دمج تلقائي.
- **مساعد خارج نطاقه:** لا يرى المجموعة أصلًا؛ وطلبه المباشر يُرجع فارغًا.

### قواعد ملزمة

| القاعدة | المرجع |
|---|---|
| المساعد يُدعى ويُفعّل ويُوقف من المدرس فقط | REQ-06 |
| الصلاحية = فعل + نطاق مجموعات، ولا تُمنح بلا نطاق | C-05 |
| المساعد لا يمنح نفسه ولا يدير مساعدًا آخر | REQ-06 |
| تغيير الصلاحية يُسجَّل في التدقيق ويُطبَّق على الطلب التالي | REQ-17 |
| إيقاف المساعد يمنع وصوله فورًا (فحص الحالة في كل طلب) | C-24 |
| إخفاء الزر ليس حماية — الفرض على RLS والدوال | PERMISSIONS §١ |
| عند إضافة فعل جديد لاحقًا لا يُمنح تلقائيًا لأي مساعد | منع توسّع صلاحيات صامت |

### حالات
- **لا مساعدين:** «لم تضف مساعدًا — يمكنك إدارة كل شيء بنفسك.»
- **دعوة معلّقة:** تظهر بحالة «لم يفعّل» مع إعادة إرسال وإلغاء.
- **مساعد بلا مجموعات:** تحذير مانع للحفظ.
- **مساعد يحاول تجاوز نطاقه:** رسالة «هذه المجموعة غير متاحة لك» + سجل تدقيق.
