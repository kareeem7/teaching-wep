# نموذج شاشة — عرض الدرس

المرحلة: 06 · الصفحة: `public/pages/student/lesson-view.html` · السكربت: `public/assets/js/student/lesson-view.js`
المتطلبات: REQ-09، REQ-18

## الغرض

عرض درس (شرح + صور + معادلات + فيديو يوتيوب) لطالب مسموح له فقط، مع قراءة مريحة على الموبايل.

## الشاشة

```
┌──────────────────────────────────────┐
│ ← التفاضل — قواعد الاشتقاق           │
│ مادة: رياضيات · الصف 3ث · مليج ٧م     │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │   [ فيديو يوتيوب مضمّن ]         │ │
│ └──────────────────────────────────┘ │
│                                       │

│                                       │

└──────────────────────────────────────┘
```

## قواعد المحتوى

| العنصر | القاعدة |
|---|---|
| الفيديو | رابط يوتيوب فقط؛ يُستخرج `video_id` ويُتحقق منه على الخادم؛ التضمين عبر iframe مولّد من معرّف موثوق |
| HTML المستخدم | ممنوع؛ يُمرَّر عبر `sanitizer.js` (اسمح بقائمة بيضاء) |
| الصور | Storage خاص + signed URL قصير العمر |
| المعادلات | KaTeX بإعدادات آمنة (`trust: false`، بلا `\href` خارجي)؛ اتجاه رياضي LTR داخل RTL |
| النص | فقرات وعناوين فقط؛ لا سكربتات ولا أنماط داخلية من المستخدم |

## فيديو: ما نتعامل معه

| الحالة | العرض |
|---|---|
| عام أو غير مدرج قابل للتضمين | يعمل داخل الصفحة |
| خاص (Private) | **لا يُفترض أنه يعمل** — رسالة واضحة (L-05) |
| محذوف/غير متاح | «الفيديو غير متاح حاليًا» + الدرس يظل مقروءًا |
| مانع للتضمين | رسالة + رابط فتح على يوتيوب كحل أخير |
| رابط غير صالح | يُرفض عند الإدخال برسالة محددة |

**لا ادعاء حماية:** الفيديو غير المدرج ليس حماية (L-04)، والتضمين لا يزيل إعلانات يوتيوب.

## الصلاحيات

- الطالب يرى الدرس إن كان عضوًا في مجموعة مسموح لها بالدرس، وكان الدرس منشورًا.
- طالب غير مسموح: 403 وليس صفحة فارغة.
- لا يرى الطالب مسودة درس.

## الحالات

| الحالة | العرض |
|---|---|
| تحميل | هيكل عظمي للفيديو والنص |
| درس بلا فيديو | يُخفى المشغّل بلا فراغ |
| بلا معادلات | لا تحميل لمكتبة KaTeX (أداء) |
| خطأ signed URL | إعادة محاولة + رسالة |

## RTL وإتاحة

- نص عربي RTL، والمعادلات وأرقام الإصدارات LTR.
- زر تشغيل واضح، والفيديو له عنوان نصّي.
- الصور لها `alt` وصفي.
- تباين كافٍ، وعرض أقصى للقراءة (٦٥–٧٥ حرفًا في السطر على الكمبيوتر).

## معايير القبول

1. لا يُقبل iframe خام من المستخدم (XSS).
2. الطالب غير المسموح لا يصل لمحتوى الدرس ولا لصوره.
3. الفيديو يعمل داخل الصفحة دون فتح موقع خارجي إلزامي.
4. معادلة طويلة لا تسبب تمريرًا أفقيًا للصفحة بأكملها.
