# نموذج شاشة — صفحة الدرس

**المرحلة:** ٠٦ · **الأدوار:** مدرس (تعديل) · طالب (عرض) · **الأولوية:** موبايل أولًا

## الهدف
قراءة درس مكتوب بمحتوى غني (نص، صور، معادلات، فيديو) بأقل تشتيت.

## التخطيط — طالب

```text
┌───────────────────────────────────────┐
│ ‹ دروسي · رياضيات ٣ث                  │
├───────────────────────────────────────┤
│ الدرس ٤: النهايات والاتصال            │
│ ─────────────────────────────────────  │
│ شرح المكتوب…                          │
│                                       │
│        lim  f(x) = L                  │
│        x→a                            │
│                                       │
│ [صورة توضيحية]                        │
│                                       │
│ ┌───────────────────────────────────┐ │
│ │ ▶ فيديو يوتيوب (مضمّن)            │ │
│ └───────────────────────────────────┘ │
│                                       │
│ [الدرس السابق]      [الدرس التالي]    │
└───────────────────────────────────────┘
```

## عناصر وقواعد
| العنصر | القاعدة |
|---|---|
| المحتوى النصي | Markdown محدود، **يُعقَّم على الخادم**؛ لا HTML/`iframe` من المستخدم |
| المعادلات | KaTeX بإعداد `trust: false`، وتُحمَّل **فقط عند وجود معادلة** |
| الصور | من Storage خاص عبر رابط موقّع قصير العمر |
| يوتيوب | يُقبل معرّف الفيديو فقط بعد تحقق الصيغة؛ التضمين بـ`youtube-nocookie` و`rel=0` |
| الإتاحة | الدرس يُعرض لمجموعات محددة فقط (RLS)، والمؤرشف لا يظهر |
| فيديو غير متاح | رسالة: «الفيديو غير متاح أو يمنع التضمين — راجع مدرسك» + رابط بديل اختياري |

## حالات
- **درس غير متاح لمجموعتك:** صفحة واضحة بلا تفاصيل محتوى (لا ٤٠٤ صامت يخفي السبب).
- **صور/معادلات تفشل:** يُعرض نص بديل، لا فراغ.
- **شبكة بطيئة:** الصور lazy-load؛ المعادلات لا تعطّل النص.

## تعديل الدرس (مدرس)
```text
[عنوان] [الصف][المادة] [المجموعات المستهدفة ▾]
[محرر النص]  [+ صورة] [+ معادلة] [+ فيديو يوتيوب]
[معاينة]  [حفظ كمسودة]  [نشر]
```

## RTL والوصول
- المعادلات معزولة بـ`dir="ltr"` داخل النص العربي؛ النص البديل لقارئ الشاشة عند وجود معادلة.
- عنوان كل قسم دلالي (h2/h3)، وترتيب قراءة منطقي.

## حدود معلنة
- يوتيوب قد يعرض إعلانات أو اقتراحات؛ المنصة لا تتحكم فيها.
- «غير المدرج» ليس حماية وصول.
- لا تُستضاف نسخة فيديو على المنصة في الإصدار الأول.
