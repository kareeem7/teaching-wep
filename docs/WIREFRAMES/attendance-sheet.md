# نموذج شاشة — كشف الحضور

**المرحلة:** ٠٥ · **الدور:** مدرس / مساعد بنطاق · **الأولوية:** الموبايل أولًا (تُستخدم واقفًا في الحصة)

## الهدف
تسجيل حضور حصة واحدة بأسرع مسار ممكن، مع منع الازدواج وتوثيق أي تعديل.

## التخطيط — موبايل

```text
┌───────────────────────────┐
│ ‹ رجوع    مليج ٧ · ٦:٣٠  │
│ الأربعاء ٤ نوفمبر         │
├───────────────────────────┤
│ [حاضر للكل]  [مسح]        │
│ المسجَّل: ١٢/٢٠            │
├───────────────────────────┤
│ أحمد سالم        ○ ○ ○ ○ │
│ منة عبد الله     ● ○ ○ ○ │
│ كريم ف.          ○ ● ○ ○ │
├───────────────────────────┤
│ [حفظ الحضور — ١٢ طالبًا]  │
└───────────────────────────┘
```

الدوائر الأربع = حاضر · غائب · متأخر · عذر (تسمية نصية أسفلها، لا لون وحده).

## التخطيط — كمبيوتر

```text
┌────────────────────────────────────────────────────────────┐
│ كشف حضور — «مليج ٧» · ٤ نوفمبر ٦:٣٠ م        [حاضر للكل]  │
├──────────────┬──────┬──────┬──────┬──────┬────────────────┤
│ الطالب        │ حاضر │ غائب │ متأخر│ عذر  │ ملاحظة        │
│ أحمد سالم     │  ●   │  ○   │  ○   │  ○   │ [        ]     │
│ منة عبد الله  │  ○   │  ●   │  ○   │  ○   │ [        ]     │
├──────────────┴──────┴──────┴──────┴──────┴────────────────┤
│ غير مرصود: ٨ طلاب — لن يُحسبوا غيابًا.   [حفظ] [إلغاء]    │
└────────────────────────────────────────────────────────────┘
```

## قواعد التصميم الملزمة
| القاعدة | المرجع |
|---|---|
| **غياب السجل ≠ غياب** — «غير مرصود» حالة عرض لا حالة مخزّنة | C-10 |
| «حاضر للكل» يملأ غير المرصود فقط، ولا يمس المرصود يدويًا | منع الكتابة فوق قرار بشري |
| الحفظ ذرّي (معاملة واحدة) ويُظهر «تم الحفظ» بعد تأكيد الخادم لا قبله | C-14 روحًا |
| التعديل بعد الحفظ يطلب **سببًا** ويسجّل قبل/بعد | C-10 |
| لا يمكن تسجيل طالب من مجموعة أخرى | C-05 |
| الحفظ المكرر لا ينشئ سجلات مزدوجة | قيد فرادة (session, student) |

## الحالات
- **حصة بماضٍ بلا تسجيل:** لافتة «هذه الحصة مضت بلا حضور مسجَّل — سجّلها الآن أو تجاهلها.»
- **فشل الحفظ:** يبقى ما كتبه المستخدم، مع شريط «لم يُحفظ — أعد المحاولة» وزر إعادة.
- **انقطاع:** تُعطَّل الأزرار مع رسالة واضحة، **ولا محاولة حفظ صامتة**.
- **مساعد خارج النطاق:** ٤٠٣/فارغ، مع رسالة «هذه المجموعة غير متاحة لك».

## RTL والوصول
- شبكة الحالات تعمل بلوحة المفاتيح (أسهم + مسافة)، وتُقرأ بتسمية صوتية: «منة عبد الله، غائب، محدد».
- لا اعتماد على اللون وحده؛ كل حالة لها نص/رمز.

## مؤجل
حضور متعدد الحصص في شاشة واحدة · QR للطالب · تنبيه ولي الأمر.
