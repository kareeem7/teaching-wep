# نموذج شاشة — إعداد الامتحان

المرحلة: 07 · الصفحات: `teacher/exams.html`, `teacher/exam-builder.html` · السكربت: `teacher/exams.js`
المتطلبات: REQ-11، REQ-14

## الغرض

بناء امتحان من بنك الأسئلة بضوابط السحب العشوائي والتوقيت والمحاولات والإفراج عن النتائج.

## 1. قائمة الامتحانات

| العمود | المعنى |
|---|---|
| الاسم | اسم الامتحان |
| المجموعات | المستهدفة |
| الأسئلة | عددها من إجمالي صالح في البنك |
| التوقيت | نمط + فتح/إغلاق |
| المحاولات | من بدأ/أكمل/لم يبدأ |
| الحالة | مسودة / مجدول / جارٍ / منتهٍ / بانتظار النشر |

## قواعد إلزامية

| القاعدة | التنفيذ |
|---|---|
| السحب على الخادم | في `exam-start`، لا في المتصفح |
| لا سؤال مكرر في محاولة | قيد + منطق السحب |
| خلط الأسئلة والاختيارات يثبت طوال المحاولة | يُخزَّن الترتيب في `attempt_questions`/`attempt_options` |
| الربط بمعرّف الاختيار لا برقمه | التصحيح بمعرّف |
| منع النشر عند نقص المؤهل | تحقق خادمي في `exams-publish` |
| الإعدادات الافتراضية آمنة | المراجعة ممنوعة، الدرجة بعد النشر (D-105) |
| حساب النهاية | `expires_at = min(بداية + المدة, إغلاق الامتحان)` |

## تنبيهات الواجهة

- عند اختيار بنك صغير: تحذير أحمر نصّي «المؤهل ٨ أقل من المطلوب ١٠ — لا يمكن النشر».
- عند تعديل امتحان منشور: «التعديل ينشئ نسخة جديدة؛ المحاولات الجارية لا تتأثر».
- لا يُسمح بتغيير عدد الأسئلة بعد بدء أول محاولة دون نسخة جديدة.

## الصلاحيات

- `exams.manage` لإنشاء وتعديل.
- `results.publish` لنشر النتائج — فعل منفصل.
- المساعد يرى فقط مجموعاته في «المجموعات المستهدفة».

## الحالات

| الحالة | العرض |
|---|---|
| بنك فارغ | تعطيل النشر + رابط «أضف أسئلة» |
| مسودة | تظهر للمدرس فقط، الطالب لا يراها |
| جارٍ | منع تعديل الأسئلة؛ يظهر «المحاولات: ٥ نشطة» |
| منتهٍ | زر «نشر النتائج» و«معاينة التوزيع» |

## RTL وإتاحة

- أرقام المدة والتواريخ حقول منفصلة مفهومة، لا حقل نص حر.
- عرض المنطقة الزمنية بجانب كل حقل وقت: «بتوقيت القاهرة».
- كل تحذير نصّي مع أيقونة، لا لون فقط.

## معايير القبول

1. تغيير أي إعداد لا يعيد كتابة محاولة جارية.
2. منع النشر عند نقص الأسئلة المؤهلة.
3. لا يصل مفتاح الإجابة للمتصفح عند بناء الامتحان.
4. النتائج لا تُظهر للطالب قبل الإعداد المعتمد.
