# نموذج شاشة — إعداد الامتحان

**المرحلة:** ٠٧ · **الدور:** مدرس · **الأولوية:** كمبيوتر أولًا

## الهدف
تكوين امتحان من البنك بضبط واضح للتوقيت والمحاولات والنتائج، **بلا إعدادات مخفية**.

## التخطيط — ثلاث خطوات

```text
[١ الأساس] ─── [٢ الأسئلة] ─── [٣ التوقيت والنتائج] ─── [مراجعة ونشر]
```

### ١) الأساس
```text
الاسم: [امتحان الجبر ٢]
المادة: [رياضيات ▾]   الصف: [٣ ثانوي ▾]
المجموعات المستهدفة:  ☑ مليج٧   ☐ شبين٦   ☐ ملحق
```

### ٢) الأسئلة
```text

الدرجة الكلية المتوقعة: ١٠ × ١ = ١٠
```


## قواعد إلزامية
| القاعدة | السبب |
|---|---|
| عدد الأسئلة المؤهلة < المطلوب ⇒ **منع النشر** برسالة واضحة | C-13 |
| تنبيه قبل النشر: «سيُسحب ١٠ من ١٠٠؛ قد تتقاطع الأسئلة» | عدالة معلنة |
| `closes_at > opens_at`، والمدة ≤ نافذة الإتاحة | منع امتحان مستحيل |
| تغيير إعدادات الجوهر بعد بدء أول محاولة **ينشئ إصدار امتحان جديدًا** ولا يمس المحاولات القائمة (R-17) | ثبات المحاولة C-14 |
| إظهار الدرجة والمراجعة إعدادان منفصلان | C-15 |
| كل حقل له تلميح يشرح أثره | تقليل أخطاء النشر |

## حالات
- **لا مجموعات:** «حدد مجموعة واحدة على الأقل.»
- **مجموعة بلا طلاب:** تحذير غير مانع.
- **بنك ناقص:** منع النشر + رابط «أضف أسئلة».
- **مسودة قديمة:** «آخر حفظ منذ ٣ دقائق» + حفظ تلقائي.
