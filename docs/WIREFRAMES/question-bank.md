# نموذج شاشة — بنك الأسئلة

المرحلة: 07 · الصفحات: `teacher/questions.html`, `teacher/question-editor.html` · السكربت: `teacher/questions.js`
المتطلبات: REQ-10

## الغرض

إدارة بنك أسئلة المدرس (اختيار من متعدد + صح/خطأ) بشكل يسهّل الوصول إلى ١٠٠ سؤال وربطها بامتحانات.

## 1. قائمة الأسئلة

```
┌──────────────────────────────────────────────────────────────┐
│ بنك الأسئلة (١٠٠)                      [+ سؤال جديد]         │
│ 🔎 بحث   [المادة ▾][الصف ▾][الموضوع ▾][النوع ▾][الحالة ▾]   │
├──────────────────────────────────────────────────────────────┤
│ # │ نص السؤال (مختصر)      │ النوع │ الموضوع │ درجة │ حالة  │
│ 1 │ مشتقة x² هي...          │ اختيار│ تفاضل   │ 1    │ منشور │
│ 2 │ مشتقة الثابت = صفر      │ صح/خطأ│ تفاضل   │ 1    │ مسودة │
└──────────────────────────────────────────────────────────────┘
```

- ترقيم وفرز، وعدّاد «صالح للاستخدام» (منشور + إجابة صحيحة) بجانب الإجمالي.

## 2. محرر السؤال

```
┌ سؤال جديد ─────────────────────────────────────────────┐
│ النوع: (•) اختيار من متعدد   ( ) صح/خطأ                │
│ نص السؤال:  [_____________________]  [إدراج معادلة]    │
│ صورة السؤال: [إرفاق]                                   │
│                                                        │
│ الاختيارات:                                            │
│  A [__________] (•) صحيحة   [صورة]                     │
│  B [__________] ( )         [صورة]                     │
│  C [__________] ( )         [صورة]                     │
│  D [__________] ( )         [صورة]   [+ اختيار]        │
│                                                        │
│ الدرجة: [1]   الموضوع: [____]   الصعوبة: [اختياري ▾]   │
│ شرح الإجابة: [____________________]                    │
│                                                        │
│                        [حفظ كمسودة]  [نشر]             │
└────────────────────────────────────────────────────────┘
```

## قواعد التحقق (تُفرض على الخادم في `question-validator.js`)

| القاعدة | السلوك عند الخرق |
|---|---|
| سؤال اختيار من متعدد: ≥ ٢ اختيارات، وإجابة صحيحة واحدة بالضبط | منع النشر برسالة محددة |
| صح/خطأ: خياران ثابتان وإجابة محددة | منع النشر |
| نص السؤال غير فارغ | منع الحفظ |
| درجة ≥ ٠.٢٥ (أو ١ افتراضيًا) | منع الحفظ |
| لا نشر بلا إجابة صحيحة | منع النشر |
| صورة: نوع وحجم مسموحان | رفض الإرفاق |

## ثبات النسخة

- السؤال المستخدم في امتحان له **نسخة محفوظة** (`question_versions`).
- تعديل السؤال لاحقًا **لا يغيّر** امتحانًا جاريًا ولا نتيجة سابقة (REQ-10).
- إشعار في الواجهة عند حفظ سؤال مستخدم: «التعديل ينشئ نسخة جديدة ولا يؤثر على الامتحانات القائمة».

## الصلاحيات

- `questions.manage` للمدرس أو المساعد الممنوح.
- المدرس لا يرى بنك مدرس آخر إطلاقًا.
- الأرشفة تمنع الاستخدام في امتحانات جديدة دون محو التاريخ.

## الحالات

| الحالة | العرض |
|---|---|
| بنك فارغ | «ابدأ بإضافة أول سؤال» + استيراد؟ (لا استيراد في الإصدار الأول) |
| سؤال مؤرشف | يظهر بفلتر «مؤرشف» فقط، وممنوع اختياره في امتحان جديد |
| سؤال بلا إجابة | شارة «غير صالح للنشر» + سبب |
| معادلة | معاينة فورية بجوار الحقل |

## RTL وإتاحة

- الكمبيوتر أولًا هنا (إدخال كثيف)، مع تكيّف للموبايل.
- معاينة المعادلة LTR داخل حقل عربي.
- تسميات صريحة لكل اختيار («الاختيار A: ...» لقارئ الشاشة).
- إضافة اختيار بلوحة المفاتيح دون فأرة.

## معايير القبول

1. لا نشر لسؤال بلا إجابة صحيحة أو باختيارات غير صالحة.
2. تعديل سؤال مستخدم لا يغيّر امتحانًا منشورًا أو نتيجة.
3. عزل كامل بين بنوك المدرسين (ISO-01).
4. كل سؤال يعرض درجته وشرحه لمن يملك الصلاحية فقط.
