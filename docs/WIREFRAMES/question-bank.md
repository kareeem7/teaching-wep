# نموذج شاشة — بنك الأسئلة

**المرحلة:** ٠٧ · **الدور:** مدرس (+ مساعد بصلاحية) · **الأولوية:** كمبيوتر أولًا

## الهدف
بناء بنك أسئلة نظيف قابل للسحب، مع ضمان أن كل سؤال «صالح» قبل دخوله امتحانًا.

## التخطيط — القائمة

```text
┌──────────────────────────────────────────────────────────────┐
│ بنك الأسئلة (١٠٠)                            [+ سؤال جديد]  │
│ [بحث في النص]  النوع ▾  الصف ▾  الموضوع ▾  الحالة ▾         │
├──────────────────────────────────────────────────────────────┤
│ ☐ │ # │ السؤال                     │ النوع │ إجابة صحيحة │ ⋯ │
│ ☐ │ ١ │ نهاية الدالة عند…          │ اختيار│ ب            │   │
│ ☐ │ ٢ │ إذا كانت f مستمرة فإن…     │ صح/خطأ│ صح           │   │
├──────────────────────────────────────────────────────────────┤
│ محدد: ٢  → [أرشفة] [إضافة إلى امتحان]                       │
└──────────────────────────────────────────────────────────────┘
```

## محرر السؤال

```text
النوع: (•) اختيار من متعدد  ( ) صح/خطأ
النص:  [...................................]  [+ صورة] [+ معادلة]
الاختيارات (اختيار واحد صحيح):
  (•) أ) …            ( ) ب) …            ( ) ج) …       ( ) د) …
الدرجة: [١]     الموضوع: [‏▾]     الصعوبة (اختياري): [‏▾]
شرح الإجابة: [...................................]
[حفظ كمسودة]   [تنشيط السؤال]
```

## قواعد إلزامية
| القاعدة | السبب |
|---|---|
| لا تنشيط سؤال بلا إجابة صحيحة واحدة | REQ-10 |
| اختيار من متعدد: ٢–٦ اختيارات، إجابة واحدة | يمنع سؤالًا ناقصًا |
| صح/خطأ: خياران ثابتان | — |
| **نسخة السؤال تُحفظ داخل المحاولة** | تعديل السؤال لاحقًا لا يغيّر امتحانًا سابقًا |
| الأرشفة تمنع الاستخدام الجديد ولا تمحو التاريخ | REQ-10 |
| المدرس لا يرى بنك مدرس آخر | C-02 |
| «إضافة إلى امتحان» لا تجاوز عدد الأسئلة المطلوب | يُدار في شاشة الامتحان |

## حالات
- **بنك فارغ:** «لا أسئلة بعد — أضف أول سؤال أو انسخ من امتحان سابق (مؤجل).»
- **سؤال غير صالح:** شارة حمراء «ناقص: لا توجد إجابة صحيحة» مع منع التنشيط.
- **بحث بلا نتائج:** نص + مسح الفلاتر.
- **حفظ فاشل:** يبقى المحتوى في المحرر، ولا يُغلق.

## RTL والوصول
- ترتيب الاختيارات أ/ب/ج/د، والمعرّف الحقيقي للاختيار مخفي عن المستخدم (C-13: الخلط لا يغيّر الإجابة).
- المعاينة تعرض السؤال كما يراه الطالب.

## مؤجل
استيراد أسئلة من ملف · حساب صعوبة تلقائي · مشاركة بنك بين المدرسين (مرفوض حاليًا).
